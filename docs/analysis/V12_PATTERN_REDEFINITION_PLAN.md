**根因（一句话）**：生产 `engine.constraint_ctx` 的 `odd_range` 按实测频次 ≥2% 阈值放宽到 `[1,2,3,4,5]`，而 `check_shape` 用理论带 `[2,3,4]`；**仅奇偶这一项就把 57.15% 抬到 68.30%**。`top_zones` 是近 500 期 top-**10**，不是 5，也不是兜底的 4。

## 第一部分　三层「规律」的重新定义（§1，本方案核心）

### 1.0 总纲：三层不是"更多含义"，而是「一个判据 + 三个标签」

> **【裁决 R-2】** P4 §2.2 指出「规律」在产品里有 5 种互斥含义，并主张「不再新增第 6 种含义」。我**完全同意 P4 对问题的诊断**（这是 V4→V11 六轮循环的机制），但**不同意它的修复方式止步于改名**。本方案的做法是：
>
> 1. **「规律」这个词从主口径中退役**，全站统一改称 **「证据项（evidence item）」**；
> 2. 每个证据项**必须且只能带一个 `layer` 标签** ∈ `{L1, L2, L3}`，标签由**确定性代码**在生成时写入，不由文案决定；
> 3. **判据只有一个口径**：`可判定`（答案唯一、代码能给对错）。凡不满足的，不得出现在 UI 的任何计数里；
> 4. 三层**不共享同一个计数**：L1 的计数是「检出/未检出」，L2 的计数是「约束满足率」，L3 的计数是「决策对的/错的」。**禁止把三层的数字相加或并列成「总规律数」**——这正是 P4 指出的「可用规律 0 vs 5 条」矛盾的根因。
>
> 理由：只改名不改判据，下一轮必然再造一个同义词（P4 §7.2 第 3 条已预言）。改名 + 强制 `layer` 字段 + 分栏计数，才能让「互相打脸的数字」在物理上无法同屏出现。

三层与 EV 的关系（**这一张表是全文的诚实边界**）：

| 层 | 一句话定义 | 能否改变单注 EV？ | 是否是 V12 的目标？ | 可交付物形态 |
|---|---|---|---|---|
| **L1 预测型** | 从历史号码推断「下一期哪些号更容易出」 | **理论上可以**（若 `p_j` 真的不均匀，`E[|T∩R|]=Σ_{j∈T} p_j`） | ❌ **不是目标**。保留的唯一理由是**污染检测** | 检测器 + 「未检出」结论 + 检出时的最高级告警 |
| **L2 结构型** | 用组合数学**精确算出**票单的形态/分布/方差/覆盖 | ❌ **不可能**（组合恒等式钉死） | ✅ **最大可交付块** | 精确数值 + 中性值对照 + 可复算命令 |
| **L3 决策型** | 让「买几注/买哪些形态/要不要信 AI」有**可打分的答案** | ❌ **不可能**（每注 `ev_ratio_full≈0.45673` 恒定） | ✅ 第二可交付块 | 打分卡（`n_correct/n`、`violation=0`、`Δpp`） |

### 1.1 L1 预测型规律（改 EV）——**不可达，降级为污染检测器**

| 项 | 内容 |
|---|---|
| **定义** | 一个形如 `f(H_t) → S ⊂ {1..33}` 的**选号函数**，满足「用 `H_t` 选出的号在 t+1 期的命中数期望 > 6·|S|/33」。等价于「存在非均匀的 `p_j`」或「存在可利用的条件结构」。 |
| **判据（冻结）** | ① as-of 回放（只用 `draws[:t]`）；② 计入**真实可执行组合数** `m` 做 BH 或 Bonferroni；③ 必须**同时在 ≥2 个互不重叠的时间段**独立通过（`p_adj<0.05`），且方向一致；④ 必须通过**固定子集口径**复核（见下「构造效应免疫」）；⑤ 效应量必须 ≥ 该 `m` 下的 MDE。 |
| **数据需求** | 3515 期 → 单检验 MDE `+3.76%`；`m=94` → `+5.78%`；`m=124`（修好 V12-01 后，**正确口径**）→ `+5.88%`。最近 150 期窗口 MDE `+18.2%`（`m` 校正后 `+28.0%`）。**结论：本数据只能排除「≥+6%」的量级。** |
| **可交付物** | ① `lottery/contamination.py`（新增，**只读**）：把现有 9 项检验 + 「最大单号 χ² 分量 + 33 重校正」+「33×33 条件转移矩阵」+「滑窗 161 段」打包成一份**污染检测报告**；② 检出时**最高级告警**（`severity="critical"`，因为这是唯一可能的「机器被操纵」信号）；③ 未检出时**唯一允许的措辞**见下。 |
| **验收命令** | 见 §3 的 `A1`（注入必检出）与 `A2`（纯随机不误报）；单条：`.venv/bin/python -m pytest tests/test_v12_contamination.py -q` |
| **诚实边界文案（冻结，逐字使用）** | **「本系统不对『下一期会开什么』做任何预测，也不具备这个能力。这一层只做一件事：检查历史开奖数据是否偏离『公平随机』到需要怀疑设备/录入的程度。当前结论：在 3515 期上，能排除单号偏置约 +20% 以上；对 +8% 及以下的偏置没有分辨力。这不是『没有偏置』，是『本数据看不见更小的偏置』。」** |

### 1.2 L2 结构型规律（不改 EV，改分布/方差/形态/合理性）——**最大可交付块**

> **L2 的性质**：它不是「从历史学到的」，而是**组合数学的恒等式**。它**不需要**样本量、**不需要** p 值、**不需要**功效——它可以被**全枚举验证到 1e-9**。这也是它唯一能诚实地被称为「规律」的理由：它永远成立。

| 子项 | 定义 | 判据（可判定） | 当前实测值 | 数据需求 |
|---|---|---|---|---|
| **L2-a 形态恒等约束** | 5 维（和值/跨度/三区/奇偶/连号）落在 `C(33,6)` 的理论带上 | 违规注数 **必须 = 0**；`actual_rate` 与 `theoretical_rate` 偏差 ≤ 理论带内；`theoretical_rate` **必须是全枚举值而非硬编码** | **生产门槛通过 68.2992%，即只剔除 31.70% 的组合**（`engine.pass_constraints` 全枚举，见 0.3-⑨）；`shape_rules_report`：和值实测均值 **100.981**（理论 102.264）、跨度实测 24.258（理论 24.306）、奇偶 2–4 占比 **0.8296**（理论 0.8257）、和值带内率 **0.9090**（理论 0.90）`[实测]` | **0 期**（纯组合数学，`C(33,6)=1 107 568` 全枚举） |
| **L2-b 奖级分布** | `P(≥1注≥r红)`、`P(≥1注中任意奖)`、`P(≥1蓝)` 的**精确值**（非 iid 近似） | 必须有 `method="exact_enum"` 标签；iid 近似值**并排显示**且标注倍数差 | n=5 低重叠：`P(≥1注≥4红)=0.024504` vs iid `0.024265`（+0.98%）；高重叠 `0.019517`（**−19.6%**）`[实测]` | **0 期** |
| **L2-c 方差/冗余** | `Ā = Σ_{i<j}A_ij/C(n,2)`，`var_ratio = 1+(n−1)(11/54)(Ā−12/11)` | `var_ratio ≥ 0` 恒成立；`Ā` 必须与**中性值 12/11** 并排 | `Ā=4.0 → var_ratio=3.3704`；`Ā=0.0 → var_ratio=0.1111`；中性 `Ā=12/11 → 1.0000` `[实测]` | **0 期** |
| **L2-d 覆盖效率** | `union_coverage ≤ 33`、不同蓝球数 `/16` | `P(≥1蓝) = min(n_blue,16)/16`（闭式最优） | 5 注互不相交：`union_coverage=30`；5 注共用 4 号：`union=14` `[实测]` | **0 期** |
| **L2-e 预算内最优组合** | 给定预算 `n` 注与目标（最小化 var / 最大化 `P(≥1蓝)` / 硬约束最大 `P(≥1注≥4红)`）的**精确最优解** | 与 iid 基准的差、与穷举/贪心解差 ≤ 1e-9 | 见 L2-b：**低重叠把 `P(≥1注≥4红)` 提到 iid 之上 0.98%，而 iid 就是天花板**（不可能超过 `1−(1−p₄)^n`） | **0 期** |

**L2 的唯一真实收益（必须说清有多大）**：

> 在一组 n=5 注的票单上，从「高重叠（`Ā=4.0`）」换成「互不相交（`Ā=0`）」，`P(≥1注≥4红)` 从 **0.019517 提到 0.024504**（+25.6%），而 iid 天花板是 **0.024265**……**等等，0.024504 > 0.024265，为什么能超过 iid？**
>
> **这是本方案里最需要说清的一个数学点**：iid 近似 `1−(1−p₄)^n` 假设各注独立，而**互不相交的票单是负相关的**（一注占了号，另一注能中的空间变小，但"至少一注中"的并集事件反而更集中）。精确枚举给出的 `0.024504` 比 iid 的 `0.024265` 高 **0.98%**，这个差就是「负相关带来的并集增益」。**它不是选号优势，是「不重复买同一批号」的结构收益**——而这个收益**完全来自「避免高重叠」**，不来自任何历史数据。
>
> 换句话说：**L2-e 能给的最大收益就是「把票单从坏配置修到好配置」，量级 ≈ +1%（相对 iid），并且一旦到达 iid 附近就封顶。** 这是本方案里**唯一**可以用「提升」二字描述的数字（提升的是 `P(≥1注≥4红)` 这个结构概率，**不是中奖率，EV 仍恒为 0.45673**）。

**验收命令**：`A4`/`A5`（见 §3），单条：`.venv/bin/python -m pytest tests/test_v12_l2_exact.py -q`

**诚实边界文案（冻结）**：**「以下是这张票的『形状』，不是『机会』：它告诉你这 n 注之间的重复程度、并集覆盖了多少号、以及「至少一注中 X 个红球」的精确概率。把重复的票换成不重复的票，会让「至少中一注」的概率略微上升（约 +1%），但**每一注的期望回报完全不变**（每 ¥2 期望约 ¥0.91，返奖率 45.67%）。」**

## 第五部分　给用户的一段话（§5，≤400 字，可直接进 UI）

> **为什么一个规律都找不到？**
>
> 因为我们过去把「规律」定成了「能预测下一期开几个号」。这个目标在数学上做不到：每注 6+1 的期望回报，在球是公平的前提下恒等于理论值，跟你怎么选号无关。我们拿 24 年 3515 期做了 124 个维度的扫描，一个都没有通过校正。
>
> **定义确实拓宽了，但拓宽的方式不是「放宽标准」。** 现在分成三层：
>
> **① 预测型**——已降级为「数据体检」。它不预测号码，只检查开奖数据有没有偏离公平到该怀疑设备的程度。答复是：能排除 +6% 以上的偏差，更小的看不见。
>
> **② 结构型**——用组合数学把这张票算清楚：几注之间重复多少、并集覆盖几个号、「至少一注中 4 个红球」的精确概率、以及把重复的票换成不重复的票能把「至少中一注」的概率抬高约 1%（每注的期望仍然不变）。这部分是精确的、可复算的、永远成立的。
>
> **③ 决策型**——AI 只做有标准答案的事（核对数字、检查参数、找哪段数据不对劲），它的每一次回答都有「对/错/没做」的打分。它不替你选号。
>
> **永远不承诺**：不承诺中奖，不承诺提高命中率；每 ¥2 的长期期望回报约 ¥0.91，返奖率约 45.67%，这两句话不会因为任何设置改变。
>
> 你可以点「🧪 验证」，让系统用随机假数据跑同一套检验——它会给出一模一样的「没找到」。
