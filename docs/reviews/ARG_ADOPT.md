## 0. 一句话结论（先给答案）

**「近期出现多少期可采纳」这个问题，在 3516 期真实数据上没有一个能成立的答案 —— 不是期数不够，而是「近期出现」与「未来有效」之间不存在可用的统计桥梁。** 本报告用 5 组独立检验证明：相邻窗口无持续性（分半一致率 0.508，零分布 0.490±0.041，p=0.391；交叉拟合斜率 t=+0.03，p=0.979）；滚动「选胜者」出号 3166 期 Δ=+0.021，t=+1.27，而短期（W=100）的 Δ=+0.038（t=+2.29）经严格零模型复算 p_perm=0.005 却**没有**样本外延续 —— 这是典型的「窗口选择偏差 + 无跨期延续」。

因此本报告给出的是**一套「有罪推定」的采纳体系**：多级判据不是为了「更容易采纳」，而是为了**把采纳这件事限制在成本可承受的极少数情形**，同时让用户看得见「系统此刻凭什么信/不信」。三个可执行阈值（第 2 章给出完整推导）：

| 你的问题 | 数据给出的答案 |
|---|---|
| **近期出现多少期可以采纳？** | **≥150 期（一整个完整阶段）**，且必须同时过 5 门（见 §2）。**「近期出现 20–100 期」不可采纳** —— 实测其样本外效应 Δ=+0.0023（n=20 入场）虽 t=+2.71，但换算成命中率只 +0.21%，远低于 150 期 MDE 的 0.7%，**小于单期决策可用的最小分辨率** |

## 2. 采纳准则的严格论证

### 2.1 为什么必须是多级判据而不是单一 e-value 阈值

单一阈值在两个方向上都失效：

- **太松**：`n_tested=124`、`α=0.05` → 期望假阳性 6.2 条。任何「取最小 p」的做法都在捡这 6.2 条。
- **太严**：`m=124` 下需要的 e-value 是 2480，而最强注入偏置只有 28.1 → 永远 0 条。于是用户看到「0 条可用」，无法区分「真的没有」与「标准定得太死」。

多级判据的用途是**把这两件事分开**：G1 管「有没有证据」，G2–G4 管「证据的方向和形状对不对」，G5 管「证据够不够大到能改变决策」，G6–G7 管「这证据是不是被看过之后才定的」。**每一门失败给出不同的状态**（`monitor` / `reversed` / `provisional` / `insufficient`），用户才能看到「差在哪」。

### 2.2 各门通过率的实测（as-of 时点 a=1200…3300，共 10 点 × 124 候选 = 1240 次判定）

| 门 | 单独通过率 | 说明 |
|---|---:|---|
| G1 存在性 | **0.1%** | 1240 次里仅 1 次（`a=1600`，候选 `sum_range{w:30,lo:45,hi:75}`，未校正 p=0.0004，校正后 0.049） |
| G2 方向一致 | 54.4% | ≈ 随机（期望 50%，加上「恰好为 0」的排除） |
| G3 三窗同号 | 25.2% | ≈ 随机 25%（$0.5^2$，因为三窗同号 = 后两窗与第一窗同号） |
| G4 间隔窗一致 | 73.0% | 高于 50%，但这是**同期相关**（75 期窗嵌在 150 期窗内），不代表跨期 |
| G5 可检出性 | **0.8%** | $\lvert\bar d\rvert \ge 0.1985$ 的情形只有 0.8% |
| G6 前置注册 | **0 / 53 假说** | `data/hypotheses.json`：53 条假说中 20 条 `registered`、33 条 `prereg_status=null`；`counters.n_tested_cumulative=0` |

**唯一通过 G1 的那条候选，用真实 `discovery.regime_of_filter` 复核后也被否掉**：

```
sum_range{'window': 30, 'lo': 45, 'hi': 75}
status = noise
近窗 Δ = +0.1191，近窗校正 p = 1.0
n_sig_eras = 0/23（24 个阶段、3516 期：没有任何阶段在多重校正后显著）
```

即：它在某个 as-of 时点的**全历史**检验上刚好过线（校正后 p=0.049，几乎贴边），但**在 23 个阶段上从未显著**。这正是 G3/G5 要拦的东西 —— 一个 23 段全不显著的候选，其全历史 p 值贴 0.05 只能是搜索噪声。**这条案例是「多级判据必要性」的最直接证据**：单看 G1 会放行它。

### 2.3 「近期出现多少期」的正面推导

设真实效应为 $\delta$（每期配对差），单期噪声 $\sigma_1 = \sqrt{729/968} = 0.86781$。$n$ 期、Bonferroni 分母 $m$、功效 0.8 的 MDE：

$$\mathrm{MDE}(n,m) = \frac{(z_{1-\alpha/2m} + z_{0.8})\,\sigma_1}{\sqrt n}$$

| $n$ | MDE ($m=1$) | MDE ($m=124$) | 相对基线 1.0909 | 每 100 期多命中 |
|---:|---:|---:|---:|---:|
| 10 | 0.769 | 1.202 | 110.2% | 120.2 |
| 20 | 0.544 | 0.850 | 77.9% | 85.0 |
| 30 | 0.444 | 0.694 | 63.6% | 69.4 |
| 50 | 0.344 | 0.538 | 49.3% | 53.7 |
| 100 | 0.243 | 0.380 | 34.8% | 38.0 |
| **150** | **0.199** | **0.310** | **28.4%** | 31.0 |
| 200 | 0.172 | 0.269 | 24.6% | 26.9 |
| 300 | 0.140 | 0.219 | 20.1% | 21.9 |
| 500 | 0.109 | 0.170 | 15.6% | 17.0 |
| 1000 | 0.077 | 0.120 | 11.0% | 12.0 |
| **3516** | **0.041** | **0.064** | **5.9%** | 6.4 |

**读法**：真实候选的效应量在 0.02–0.12。要让 0.12 量级在 $m=124$ 下可检出，$n \ge 100$ 仍不够（$n=100$ 的 MDE=0.380 > 0.12）；$n=150$ 的 MDE=0.310 也 > 0.12；**要到 $n \approx 1000$ 期（≈6.7 年），MDE 才降到 0.120**。

这给出一个必须写进 UI 的诚实陈述：

> **在 3516 期、$m=124$ 的现实下，任何「近期」窗口（≤150 期）都不足以检出真实量级的效应。所谓「近期可采纳」在数学上只能指「近期没有反向证据」，不能指「近期有正向证据」。**

所以 §1.1 的 $n \ge 150$ 门槛的真实含义要精确表述为：**150 期是「可以开始判定（而不是已经有证据）」的最小窗口**；它能判定的只有**反向**（G2/G3/G4 的降级判据），不能判定**正向采纳**。

### 2.4 「$n=20$ 入场效应 t=+2.71」为什么不构成采纳依据

这是本报告最需要小心处理的一条，因为它看起来是真的。实测：

```
n=20 入场（最近 20 期 Δ 均值 > 0）→ 接下来 150 期 Δ 均值（减横截面均值）
Δ = +0.00227，t = +2.71，p = 0.007，n = 7300
随机化零模型（每期在候选间重排）：t 分布 +0.05 ± 0.74，|t| 95% 分位 1.21 → p_perm = 0.000
分半复核：前 1658 期 vs 后 1658 期，候选级 sign 一致率 0.508（零分布 0.490±0.041，p=0.391）
交叉拟合：前半均效应 → 后半均效应，斜率 t = +0.03，p = 0.979，R² = 0.0000
```

**结论：这个 t=+2.71 不是「持续性」，而是「同期横截面结构」。** 证据链有三条，一致指向同一解释：

1. **交叉拟合完全归零**（斜率 t=+0.03, R²=0.0000）。如果「最近 20 期好 → 未来好」是真，前半数据上强的候选在后半也必须强。实测完全没有。
2. **分半 sign 一致率 0.508 ≈ 0.490（随机）**。这是比交叉拟合更粗的判据，同样为零。
3. **随机化零模型 p_perm=0.000**：这意味着该效应**确实不是每期候选间随机重排能解释的** —— 它反映的是候选之间真实的**水平差异**（有些候选的 $\bar d$ 长期略高于其他，因为 $\sigma$ 不同、杠杆不同）。而「水平差异」不能用于预测：它不随窗口变化，被横截面减均值后应当消失，但重叠窗口让 7300 个观测里同一锚点贡献 124 个相关观测，从而把「锚点内的横截面相关」放大成了 t≈2.7。

经济意义进一步否定它：$\Delta = +0.00227$ 等于**每 1000 期多命中 2.27 个红球**（基线 1090.9），提升 **0.21%**。

### 2.5 现行 `_long_term_ok` 四条件的评价与建议

`patterns_runtime.py:138-143`：

```python
_long_term_ok = (
    (status in USABLE_STATUSES)          # persistent
    and h.get("status") == "validated"
    and h.get("prereg_ok") is True
    and _is_replayable
)
```

**评价：方向正确，但缺两门，且有一门在现行数据上永远不会打开。**

| 现状 | 问题 | 建议 |
|---|---|---|
| 只认 `persistent` | `persistent` 的定义是「最近阶段显著」——而 `regime` 的 MDE 在 150 期、$m=32$（`ERA_FAMILY_M`）下是 0.31，比任何真实效应都大 → **`persistent` 结构上不可能出现**（实测 38 `noise` / 2 `stale` / 0 `persistent`） | 保留，但 UI 必须说明「该档在当前数据上为空是数学必然」 |
| 无 G5（可检出性） | 一个 $\bar d = 0.02$ 的候选只要碰巧过了校正就会进 `usable` | **加**：$\lvert \bar d_{\text{近150}}\rvert \ge \mathrm{MDE}(150,1)=0.199$ |
| 无 G3/G4（形状门） | 无法区分「稳定弱正」与「刚翻转」 | **加**：三窗同号 ∧ 间隔窗一致 |

**逐条落到现有代码**（改 `patterns_runtime.build_snapshot` 的 `_phase_ok` 分支）：

## 3. 放弃 / 失效准则的严格论证

### 3.1 「阶段规律容易失效」的量化

用户直觉「近期出现的规律更容易失效」在数据上**方向是对的**，但机制不是「近期规律天生更脆」，而是**近期规律的证据量天然更少**。等价表述：设采纳时效应为 $\delta$、证据量为 $n$，则效应消失所需的期数 ≈ $n$（因为要重新积累同等证据量才能推翻）。所以：

- 用 20 期采纳的规律，约 20 期就该被推翻；
- 用 150 期采纳的规律，约 150 期才可能被推翻；
- **推翻的速度与采纳时的证据量成正比** —— 这就是「近期规律容易失效」的精确形式。

这直接给出降级判据的设计原则：**降级所需的证据量不得小于采纳时的证据量**。若用「连续 3 窗符号为负」降级（3 窗 = 450 期证据），而降级对象是用 150 期采纳的，就出现了「**降级比采纳更容易**」的不对称 —— 这会让系统对「真规律」的误杀率远高于漏检率。

### 3.2 降级判据的误报率标定（纯噪声模拟，20,000–400,000 次）

| 判据 | 定义 | 纯噪声误报率 | 评价 |
|---|---|---:|---|
| D1 | 连续 $k$ 窗符号为负 | $k=1$: **49.97%**；$k=2$: 24.97%；$k=3$: **12.42%**；$k=4$: 6.26% | **✗ 不可用**：$k=3$ 误杀 1/8 |
| D2 | 连续 $k$ 窗各有单侧 $t<-1.645$ | $k=1$: 5.12%；$k=2$: **0.30%**；$k=3$: **0.01%** | ✓ 激进否决，适合 `rejected` |
| **D3** | 最近 300 期合并单侧 $t<-2.0$ 且方向相反 | **2.40%**，乘方向条件 ≈ **1.2%** | ✓ **推荐主判据** |
| D4 | 近期效应 $< -0.5\,s_0$（$s_0$=采纳时效应） | 由 $s_0$ 决定：$s_0=0.31$ 时反转幅度 0.46，$z=6.56$，可判定 | ✓ 与 G5 天然配套 |

**为什么选 D3 而不选 D2**：D2 的 0.30% 太保守，在 3516 期里几乎不可能触发（$0.003 \times 124 \approx 0.37$ 次），等于「永不放弃」。D3 的 1.2% 在 124 候选上期望约 1.5 次误报，**是能真正运转起来的量级**；同时 300 期 = 2 个完整阶段，满足「降级证据量 ≥ 采纳证据量」的原则。

### 3.3 与现有状态机的对齐

现有 `regime.regime_status` 已实现 `fading`（上一阶段显著、最近不显著）与 `stale`（最近显著距今 > 300 期）。**这两档的判据本身是对的，但它们都依赖「最近阶段曾显著」—— 而在 $m=32$ 的 `ERA_FAMILY_M` 下，150 期阶段从未显著过（实测 0/23 段）**。于是 `fading` / `stale` 在现行数据上只能由「早期曾显著」触发（实测 2 条 `stale`），无法承担「近期规律失效检测」。

建议：**在 `usable_phase` 档打开时，用 D3 独立于 `regime` 的 `fading` 做一道并联降级**，写进 `rule_lifecycle`：

```python

    recent = r.get("rolling") or {}
```

## 4. 预测价值评估体系：Δ + t + 前置注册

### 4.1 「统计显著」与「预测有用」的明确区分

这两个概念在现行系统里被混用过（`counts["usable"]` 曾等于 `usable_long_term + usable_phase`，已被 V12-04 修正为不跨层相加 —— 这个修正方向完全正确）。本报告给出形式化区分：

| | 统计显著 | 预测有用 |
|---|---|---|
| **定义** | $H_0$ 下观测这么极端的概率 < $\alpha$ | 在**未参与选择**的数据上，$\Delta$ 的 95% CI 下界 > 0 **且** $\Delta \ge \mathrm{MDE}$ |
| **能否靠加样本买到** | **能**：$\delta=0.02$ 需 7406 期才显著 | **不能**：增益 = $\delta$，与 $n$ 无关 |
| **对多重检验的敏感性** | 高（$m=124$ → 阈值 ×124） | 不变（$m$ 只影响能否判定，不影响 $\Delta$ 本身） |
| **数值演示** | 纯噪声 $n=150$: 5.3% 被判显著；$n=500$: 6.3%；$n=1500$: 4.3%（名义 5%） | 见 D2 表 |

**关键数值（D2 模拟）**：

```
δ=0.02 → 需 n≈ 7406 期才显著（m=1）；每 1000 期额外命中 20.0 个
δ=0.05 → 需 n≈ 1208 期才显著（m=1）；每 1000 期额外命中 50.0 个
δ=0.10 → 需 n≈  301 期才显著（m=1）；每 1000 期额外命中 100.0 个
δ=0.20 → 需 n≈   73 期才显著（m=1）；每 1000 期额外命中 200.0 个
```

**读法**：一个 $\delta=0.02$ 的「显著规律」，在 7406 期后会被判定为真，但它的预测增益仍然是每 1000 期 20 个红球 —— **在 3516 期上就是总共 70 个**，相对于 3835 个命中的基线是 1.8%。这就是「显著」与「有用」的全部差距。

### 4.2 评估体系的三级落地（对应用户要求的「配对差 Δ + t 值 + 前置注册」）

```
V1 统计显著   全历史配对 t，p × m_cum < 0.05
              ↓ 必须同时满足
V2 预测有用   样本外配对 Δ 的 95% CI 下界 > 0 且 Δ ≥ MDE(n_oos, 1)
              ↓ 且样本外数据必须
V3 前置注册   在 FROZEN_ISSUES=150 期冻结期内从未被查看
```

**实测结果**：

| 级别 | 实测 | 说明 |
|---|---|---|
| V1 | `n_tested=124`，`best_quick_p_adjusted=0.081` | **连 V1 都没有** |
| V2 | 滚动「选胜者」出号 3166 期：Δ=+0.0213，t=+1.27，p=0.203 | 无通过 |
| V3 | 前置注册模拟（7 时点 × 124 候选，累计 868 次检验）：**passed=0** | 无通过 |

**「选胜者出号」的抖动本身就是一个警告**：

| 窗口 $W$ | Δ | t | 随机选号零模型 $p_{perm}$ |
|---:|---:|---:|---:|
| 30 | +0.00109 | +0.07 | 0.950 |
| 50 | +0.01797 | +1.08 | 0.165 |
| 100 | **+0.03847** | **+2.29 (p=0.022)** | **0.005** |
| 150 | +0.02133 | +1.27 | 0.175 |
| 300 | +0.03231 | +1.90 | 0.030 |

**$W=100$ 那一行必须敲警钟**：它在朴素 t 检验下 p=0.022、零模型下 p_perm=0.005，看起来「找到了」。但：
1. $W=30/50/150/300$ 全部不显著 —— **一个真规律不会只在一个特定窗口宽度上生效**。这是多重比较（5 个窗口 × 124 候选 = 620 次）下的选择性结果。
2. 交叉拟合证明无跨期延续（§2.4）：前半最强的候选在后半 Δ 反而为负（前 5 名：−0.0009；前 20 名：−0.0096）。

**这正是「统计显著 ≠ 预测有用」的现实版本**：$W=100$ 的结果在统计上「显著」，但在**预测上**毫无价值 —— 它不能告诉你「下一期用哪个窗口」。

## 5. 自我延续性：正面回答「刚采纳就失效」

### 5.1 `PHASE_USABLE_STUDY` 的 r=0.124 是否推翻了「采纳近期规律」？

**是。但原文的论证比需要的弱，而且原文的「无持续性」判定方法本身也可以被反过来质疑。** 我做了两件事：

**(一) 逐字复现原文**：8 候选、不重叠 150 期窗、n=168：

```
r = +0.1239，n = 168，±1.96/√n = ±0.1512 → |0.1239| < 0.1512 → 无持续性 ✓ 复现成功
```

**(二) 把口径扩到全 124 候选（n=2604）**，结果变得「看似显著」：

```
r = +0.0399，n = 2604，±1.96/√n = ±0.0384 → 0.0399 > 0.0384 → 「有持续性」
整段位移零模型：r 分布 +0.0003 ± 0.0155，p_perm = 0.000
```

**如果只看这一行，会得出「原文错了，其实有持续性」的相反结论。** 这正是本报告必须正面处理的点。我用了三个独立判据，一致否掉它：

| 判据 | 结果 | 解读 |
|---|---|---|
| **分半一致性**（前 1658 期 vs 后 1658 期，候选级 sign） | 一致率 **0.508**，零分布 0.490±0.041，p=0.391 | 无跨期结构 |
| **候选级 前/后半窗口均值相关** | r = **−0.0565**，零分布 +0.0027±0.0943，p=0.540 | 无 |
| **交叉拟合**（前半均效应 → 后半均效应） | 斜率 t = **+0.03**，p = **0.979**，R² = **0.0000** | 完全无 |
| **逐候选 49/124 超阈** | 零模型（置换 B 的时间顺序）：**53.1 ± 5.8** 个，且实测 49 **低于**零模型均值 | 不是簇级持续性 |

**结论**：全 124 候选的 r=+0.0399 是**「候选间水平差异」与「21 个窗口的小样本」共同造成的伪影**。单候选 n=21 时，r 的抽样 sd ≈ 1/√20 = 0.224，所以 |r|>0.0384 在纯噪声下期望约 62 个 —— 实测 49 个，**低于**随机期望。原文用 8 候选、n=168 判定「无持续性」在方向上完全正确，只是样本量小到容易被质疑；扩样后结论**不变且更硬**。

**所以：这个研究不是「推翻」了采纳近期规律的合理性 —— 它推翻的是「只凭近期证据就采纳」这件事本身。** 两者区别很重要：如果采纳时**额外要求**「全历史有存在性证据（G1）+ 形状门（G2–G4）」，那么采纳的对象就不是「近期规律」而是「**全历史规律在近期的复核**」，这不在原文的否证范围内。

### 5.2 那么「刚采纳就失效」怎么防？

三条结构性防线，每条都可落地：

**防线 1：采纳对象换位（最重要）。**
不采纳「近期出现 20 期」的规律，只采纳「**全历史有存在性证据（G1 通过）且近期未反向（G2–G4 通过）**」的规律。前者在 3516 期数据上不可判定（§2.3 的 MDE 表），后者在逻辑上被 G1 保护 —— G1 通过意味着效应**不只存在于近期**，因此「近期数据恰好特殊」这个失效机制不适用。

**防线 2：冻结期把「采纳」与「验证」分开。**
`FROZEN_ISSUES=150` 已经实现，但**当前没有生效**：`data/hypotheses.json` 里 `counters.n_tested_cumulative=0`，53 条假说中 20 条 `registered`、33 条 `prereg_status=null`，且没有任何一条走过 `evaluate_prereg` 判定（`prereg_status` 无 `passed`/`failed`）。这意味着**「采纳」这一步在系统里实际上不存在** —— 所有规律都停在 `registered`，而 `usable` 需要 `prereg_ok is True`，所以永远为 `False`。

> **这是一个必须指出的实施断点**：`_long_term_ok` 的 `prereg_ok is True` 条件与 `evaluate_prereg` 的 `batch_sizes[batch_id] >= MIN_BATCH_SIZE(10)` 条件叠加后，若注册期号距当前不足 `FROZEN_ISSUES=150` 期，则 `evaluate_prereg` 全部 `skipped`，`n_tested_cumulative` 永不增长，`prereg_ok` 永不置 True。**结果是「0 条可用」不是数据结论，而是施工期的必然。** 修复方式：核对 `evaluate_after_issue` / `frozen_until_issue` 的写入口（`register_prereg`）是否被调度器以正确的期号调用。

**防线 3：D3 降级 + `usable_phase` 自动关闭。**
`PHASE_USABLE_AUTO_OFF_T = -2.0`（`config.py:328`）**只被定义了，没有任何消费点** —— 全仓 `grep` 只在 `patterns_runtime.py:67` 与 `config.py:325` 的**注释**里出现，没有代码读取它。也就是说「显著劣于基线则自动关闭」目前是一句注释，不是一个行为。需要接线到 `usable_phase` 的累计配对差序列（即 A2 改动）。

### 5.3 诚实结论

**在 3516 期真实数据上，「采纳近期规律」没有可用的统计依据。** 本报告不掩盖这一点，但也不把它写成「不可能」：

- **不能说「不可能」**的理由：数据只覆盖 23 年、3516 期。真实效应若在 0.02 量级，需要 7406 期（≈49 年）才能判定（§4.1 D2 表）。**现在的「找不到」等价于「在现有样本量下不可判定」，不等价于「证明不存在」。**
- **必须说「现在不能采纳」**的理由：任何在 $n \le 150$ 的窗口上做出的采纳决定，都落在 MDE = 0.1985–1.202 的盲区里（§2.3）。在这个盲区里，观测到的「显著」全部来自搜索噪声的 6.2 条期望假阳性。
- **因此本报告的建议是「保持 0 条可用，但把每一门的差距显示出来」**：`usable=0` 是正确的输出，但「0 条」必须配「最近一条候选差在 G5（$|\Delta|=0.12 < 0.199$）」这样的说明，用户才不会把「0」读成「系统没在工作」。
