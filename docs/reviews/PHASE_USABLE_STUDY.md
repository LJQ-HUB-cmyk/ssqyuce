# 「阶段性规律」可行性研究（Phase-Usable Patterns）

> 日期：2026-10-18
> 触发：用户提问「3515 期找不到显著规律，是不是要求太严苛？既要长期通用规律，也要**阶段性可用规律**，只要当前可用、能指导预测就行」
> 结论：**「当前阶段显著即用于出号」这个标准已被数据证伪；但它作为「可观察、可度量、可随时关闭」的档位是值得做的**
> 数据：本机真实 3515 期（2003001–2026118）

---

## 一、先说清楚一件重要的事

用户的直觉有一半是对的，但需要区分两个完全不同的概念：

| 概念 | 定义 | 是否成立 |
|---|---|---|
| **统计显著性** | 「这个效应在噪声下不太可能是巧合」 | 在 3515 期上**确实找不到**（V4/V6 已证） |
| **长期通用规律** | 效应在整个历史上稳定存在 | 找不到（χ² 与均匀随机不可区分） |
| **阶段性规律** | 「某段时间内有效，现在可能仍有效」 | **本次研究直接检验 → 不成立** |

关键问题不是「标准严不严」，而是：**「当前阶段有效」这件事，能不能预测「下一期有效」？**

如果能 → 阶段性规律可用；如果不能 → 它只是一次次的事后描述。

---

## 二、研究设计与结果（四组独立检验）

### 检验 1：当前是否存在「最近阶段显著」的规律？

对 91 组维度 × 参数做完整扫描，看状态机给出什么：

| 状态 | 条数 |
|---|---|
| `noise`（各阶段均不显著） | **38** |
| `stale`（曾显著，已被新数据推翻） | 2 |
| `persistent`（持续有效） | **0** |
| `emerging`（仅最近阶段显著） | **0** |

**结论**：连「最近阶段显著」的规律都一条都没有。不是标准严，是最近阶段连噪声级别的显著都没出现。

### 检验 2：最近 150 期是否有「集体同向」的迹象？

切分「历史 200–3365 期」与「最近 3365–3515 期」，对比各维度的效应量 Δ（观测 − 期望）：

| 维度 | 历史 Δ | 最近 Δ | 最近 z |
|---|---|---|---|
| hot (w=30) | −0.0069 | **+0.0958** | +1.31 |
| hot (w=50) | +0.0162 | **+0.1158** | +1.71 |
| hot (w=100) | +0.0194 | **+0.1091** | +1.53 |
| cold (w=30) | +0.0216 | +0.0158 | +0.23 |
| cold (w=50) | +0.0105 | −0.0642 | −1.00 |
| repeat | −0.0126 | **+0.1024** | +1.46 |
| neighbor | −0.0206 | **+0.1085** | +1.62 |
| omission_high | +0.0171 | −0.0976 | −1.36 |

**表面上看很像信号**：8 个维度里 6 个正偏离，且多个 z > 1.5。

### 检验 3：这个「同向性」是真信号还是随机波动？（随机对照）

随机抽 200 个 150 期窗口，统计「8 个维度中正偏离的个数」：

```
正偏离个数分布：[1, 11, 8, 48, 53, 49, 18, 11, 1]   （下标=个数）
真实最近窗口：6 个正偏离
随机下 >= 6 个的概率：15.00%
```

**结论**：**15% 的概率**随机就能出现同等程度的同向性。这完全在正常波动范围内，**不能作为信号**。

> 这是本项目反复出现的同一个教训：**看起来有结构 ≠ 有信号**。
> 6/8 同向确实"像那么回事"，但随机窗口每 6~7 次就有一次如此。

### 检验 4（决定性）：如果真的按「当前阶段最佳」出号，长期表现如何？

**做法**：滑动窗口，每期用「最近 150 期表现最好的维度」来出号，模拟「只用当前可用规律」的真实策略。

结果（3165 期滚动回测）：

```
平均命中 1.0961  vs  基线 1.0909
Δ = +0.0051 ± 0.0305
t = +0.33   →  不显著
```

**结论**：**3165 期下来，优势只有 0.005 个红球/期，且完全不显著**。这个「优势」只有可检出阈值的 1/8。

### 检验 5（必要条件）：阶段性规律能否自我延续？

如果「当前阶段有效」是真规律，那它应该**延续到下一个窗口**（否则无法用于预测）。

对比相邻 150 期窗口的效应量：

```
相邻窗口相关性：r = +0.1239
95% 容差：±0.1512
→ 无统计意义上的持续性
```

**结论**：**上一窗口表现好，不能预测下一窗口也好**。这是「阶段性规律可用」假设的**直接否证**——
因为用它出号的前提就是「当前有效 → 下期有效」。

## 三、结论

### 3.1 技术上：标准不是太严，是「阶段性」本身不成立

四组独立检验一致指向同一结论：

1. 当前连 `emerging` 级别的规律都**没有**（0/91）
2. 最近窗口的集体同向性，随机 15% 就能出现
3. 按「当前最佳」出号，3165 期 Δ=+0.005，t=0.33 **不显著**
4. **相邻窗口无持续性**（r=0.12，容差 ±0.15）—— 这是最致命的一条

第 4 条尤其关键：**即使某个规律"最近 150 期表现好"，它也不能用来预测下一期**。
所以「阶段性规律」即便存在，也**不可用于出号**，只能用于事后描述。

### 3.2 但用户的诉求是合理的，应该用「可观察 → 可度量 → 可关闭」来承接

用户真正想要的是：**不要只用一套极严标准把一切都判死，要能看见"当前有什么在用"**。

这一点完全合理，而且现有系统确实做得不够：`emerging` 直接归入 monitor，
用户在界面上只看到「0 条可用」，看不到**系统当前到底信什么、效果如何**。

### 3.3 建议的落地方案：新增 `phase_usable` 档（可选、可关闭、效果强制度量）

| 项 | 设计 |
|---|---|
| **状态纳入** | `persistent`（长期）+ `emerging`（阶段新兴）**+ `fading`（上一阶段刚失效但尚未陈旧）** |
| **默认开关** | **默认关闭**（`LOTT_PHASE_USABLE=0`），用户可显式打开 |
| **前置条件** | 必须**先通过前置注册**（`prereg_ok`）+ 最近阶段 A/B 不劣于基线 |
| **强制度量** | 打开后，每期记录「阶段规律出号 vs 基线」的配对差，**在界面显著位置展示累计 Δ 与 t 值** |
| **自动降级** | 累计配对检验显示明显劣于基线（如 t < −2）→ 自动关闭并告知原因 |
| **诚实文案** | 明确写「本档基于"当前阶段"假设，该假设在 3515 期数据上未获支持；打开后请以实测 Δ 为准」 |

**核心原则**：不隐瞒、不夸大，但**给用户选择权**，并用**真实数据说话**。
